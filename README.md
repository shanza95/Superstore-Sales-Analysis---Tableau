# Superstore-Sales-Analysis---Tableau
This project uses Tableau to explore and visualize sales performance from the popular Superstore dataset. The goal was to identify trends, spot problem areas, and create an interactive dashboard that gives a clear overview of how the business is doing.

The dashboard provides a clear breakdown of sales and profit across different regions, categories, and sub-categories. It highlights top-performing products as well as areas with low profitability, helping identify opportunities for improvement. Interactive filters allow users to explore data by customer segment, date range, and product type. The use of bar charts, line graphs, and heatmaps makes trends easy to spot and understand, offering quick, actionable business insights
